# V10.1 — action timing and paired task evidence

V10.1 adds a retrospective, all-record characterization of neural-triggered action timing to the existing paired first-contact study.

The exact-count revision makes validation-derived warning boundaries algebraically stable, preserving all 576 original labels and whole-seed intervals. It adds 18 boundary/regression tests, an all-record post-burst stage recheck, a regenerated Fig.4, explicit RF/statistical definitions and a fixed implementation citation. Original records, calibrations, registrations and Fig.1–3 remain unchanged; the IPS affiliation uses Kitakyushu.

- Connects shared trigger/burst schedules to 15 P/R pairs with distinct first-contact outcomes; records the zero-delay RF-0 25% contact examples.
- Preserves all frozen data, registrations, calibrations, primary/secondary statistics and the four main figures.
- Updates the scientific contribution, abstract, results and conclusion around action timing and finite-horizon task evidence.
- Retains the executable evidence interface, second plant adapter and 11+3 labelled checker challenges.
- Uses one italic affiliation line with the author email; all 13 panel labels use parentheses through vector-only additions to preserved figure assets.
- Provides a separately named PDF, complete active sources, reproducible timing tables and an exact frozen V10 source/PDF set.

The paper and accompanying tables state the analysis definitions, units, uncertainty and model scope. V10.1 introduces no new neural simulations, fitted thresholds or confirmatory hypothesis tests. The original generating metadata remain unchanged.
