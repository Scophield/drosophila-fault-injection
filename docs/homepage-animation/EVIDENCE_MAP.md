## Reconstruction and audit boundary

The preparation script calls the scientific checkout's existing `analyze_burst_end.reconstruct` and `replay_audit_v9.check_record`. It exports original straight motion subsegments and event times, not a new plant approximation. The renderer evaluates positions inside those segments; heading changes only at original segment ends. The command curve uses the last recorded sample (post-step), not fabricated spikes. Exact first-contact poses and curves freeze at contact while the declared observation clock can continue to 1000 ms.

The 50-mm ring represents center distance; static decorative icons have no physical size or wing-motion interpretation. The finite task uses one burst followed by slower walking. Contact-free completion at 1 s is not sustained avoidance, a biological tolerance threshold or device-level reliability evidence.
