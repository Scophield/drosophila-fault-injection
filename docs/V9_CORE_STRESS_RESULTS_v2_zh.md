## 事后诊断与解释边界

主实验 144/144 个控制律配对具有相同触发时刻与触发前轨迹。控制律共享触发规则，但后续转向不同。

- proportional 健康最小安全间距：中位数 33.084 mm，范围 [13.880, 39.641] mm。
- relay 健康最小安全间距：中位数 41.425 mm，范围 [39.244, 42.188] mm。
因此，健康成功数一致不等于安全裕量、执行努力或完整控制质量相同。该对比支持系统上下文依赖，不识别独立于健康裕量的纯故障耐受优势。
主实验各自停止与共同停止的最大单对比值差为 0.003242567，所有组中位数均不变，旧版大幅 exposure 效应不能作为当前主发现。
候选预测相对执行器基线的核心特异度增量为 9.818 pp，描述性整簇区间 [6.569, 13.406]。该增量分析是登记后的描述性补充，不是新确认性假设或新算法。
压力测试的 20000 个 bootstrap 重采样中，18024 个含正类，1976 个不含正类；灵敏度区间条件于前者。只有两次失败，不能验证“完美预警”。
旧 original/gated 六簇 25% 交互 p=.25 仍按旧协议保留，不能被新控制律结果覆盖或称为复现。
