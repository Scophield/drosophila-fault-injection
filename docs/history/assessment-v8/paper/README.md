# Paper sources

Current artifact version is `assessment-v8`; start with
`fly_connectome_fault_assessment_v8.pdf`, `fly_connectome_supplement_v8.pdf` and
`../REVIEW_MATERIALS.md`. The supplement consolidates the complete current tables,
figures, endpoint definitions and provenance, including the 72-record factorial
comparison and six-cluster loss/gain analysis. `PROTOCOL_v8.md` defines this
revision; `PROTOCOL_v2.md` through
`PROTOCOL_v4.md` are historical revision documents. The release manifest identifies the matching PDF,
source, data and scripts. Earlier protocol/review files are preserved as history.

`main.tex` includes the sections and generated controller results under `sections/`,
the included `figs/` PDFs and `refs.bib`.
`main.pdf` is rebuilt from these sources during the repair.

See [PROTOCOL_v2.md](PROTOCOL_v2.md) for the complete historical F1-F5 dose table and
[PROTOCOL_v3.md](PROTOCOL_v3.md) for earlier cohort/window analysis and original
whole-brain evaluation. [PROTOCOL_v4.md](PROTOCOL_v4.md) distinguishes late activity
from unequal stopping times and defines the paired controls. [../REPRODUCE.md](../REPRODUCE.md) gives
commands. Compile with tools/build_paper.ps1 and a new BuildDirectory from the repository root; it
stages sources in a new directory so stale paper/main.bbl cannot shadow fresh references.
The submission source uses `url` for printable addresses, with no `hyperref`.
Run `python tools/qa_pdf.py --pdf paper/main.pdf --out audit/my-pdf-qa --submission`
from the repository root to check links, bookmarks, forms, encryption and version,
then inspect the rendered pages. This local check is not portal certification.

Figure 1 is generated by `../tools/plot_overview_v7.py`; the previous mapped
pathway (`../tools/plot_pathway_v4.py`) is retained as Supplementary Figure S8.
Figure 2 uses
`../tools/plot_prospective.py`; Figure 3 uses `../tools/plot_horizons_v4.py`.
Supplementary Figure S9 uses `../tools/plot_controller_fault_v8.py`; lines in
both paired activity plots preserve seed/bearing identity across deletion doses.
Individual historical activity, seed/window sensitivity and prospective results
are included with explicit legends in `supplement.pdf`, including open-loop curves.
`tools/build_supplement_v5.py` creates the supporting PDF from saved measurements.
Corrected sign-specific hub contrasts,
predictive safety budgets and hardware reliability remain unmeasured.
