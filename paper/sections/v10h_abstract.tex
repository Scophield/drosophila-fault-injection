We assess how connection loss affects action timing and first contact in a fly-connectome spiking network, using 576 test episodes organized into paired campaigns. Both feedback laws complete 48/48 healthy RF-0 tasks. At 50\% connection-row deletion, proportional/relay 1-s success is 37/48 versus 48/48; the prespecified secondary net-loss contrast is $-22.9$\,pp (95\% whole-seed CI $[-33.3,-12.5]$). Recalibrated RF-A/B each yield an uncertain $-4.2$\,pp $[-12.5,0]$; unequal reserve, recalibration and cohorts limit attribution. Shared action schedules yield law-discordant contacts, while a frozen command warning detects only 2/13 RF-0 contacts. To quantify audit value, we froze 111 additional software fixtures across two plants. Full checks detect 81/87 corruptions versus 36/87 for trusted-header checks, rejecting 0/24 valid controls; six fly corruptions remain undetected. Historical re-scoring revises terminal-burst counts from 13/17 to 7/17. These measurements connect conditional task preservation with quantified audit information and explicit blind spots.
