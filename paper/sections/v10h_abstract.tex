We quantify conditional closed-loop task preservation under connection loss in a fly-connectome spiking network and audit gains from checking the supporting records. Across 576 test episodes organized into paired campaigns, 50\% connection-row deletion yields a prespecified secondary RF-0 relay-minus-proportional net-loss contrast of $-22.9$\,pp (95\% whole-seed CI $[-33.3,-12.5]$). Recalibrated RF-A/B each yield an uncertain $-4.2$\,pp $[-12.5,0]$; unequal reserve, recalibration and cohorts limit attribution. Shared action schedules yield law-discordant contacts, while a frozen command warning detects only 2/13 RF-0 contacts. In a separate, fixed 111-ID software catalogue across two plants, Full checks detect 81/87 corruptions versus 36/87 for trusted-header checks, rejecting 0/24 valid IDs and retaining six fly misses. These results combine conditional task measurements with quantified record-consistency audit gains and limits.
