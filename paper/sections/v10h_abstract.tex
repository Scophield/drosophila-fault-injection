We assess how connection loss affects action timing and first contact in a fly-connectome spiking network, using 576 test episodes organized into paired campaigns under two frozen feedback laws. Both laws complete 48/48 healthy RF-0 tasks. At 50\% connection-row deletion, 1-s proportional/relay success is 37/48 versus 48/48; the prespecified secondary net-loss contrast is $-22.9$\,pp (95\% whole-seed CI $[-33.3,-12.5]$). Separately recalibrated, same-prior RF-A/B each yield an uncertain $-4.2$\,pp $[-12.5,0]$. Unequal healthy reserve, recalibration and test cohorts limit attribution. Post-hoc analysis finds later mean triggers at 50\% deletion, yet identical schedules yield law-discordant contacts. Among 543 event-free burst completions with follow-up, subsequent command features are zero: late outcomes occur during an observed walking regime. A frozen command warning detects only 2/13 RF-0 contacts; an exact-count definition stabilizes its boundary semantics. An executable evidence interface checks pairs, clocks and labels, with independent replay and reuse on a delayed tank. Together these measurements resolve stages of finite-horizon preservation.
