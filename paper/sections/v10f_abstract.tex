Closed-loop fault experiments must distinguish neural activity from task failure while preserving pairing and causal timing. We present an executable evidence interface that checks campaign invariants and delegates input and plant semantics to native replay. A fly-connectome controller and an independent delayed tank reuse the same checker. Each adapter detects eleven predefined challenges through common checks and three through native replay; a passing synthetic logger exposes the absence of execution authentication. Two prospective receptive-field realizations, independently recalibrated and tested, qualify a retained 24-seed-cluster baseline. At 50\% connection-row deletion, the secondary relay-minus-proportional net-loss contrast changes from $-22.9$ percentage points to $-4.2$ in each new map. Both new 95\% intervals include zero, with four-test Holm $p=1$. Sparse failures, unequal healthy clearance and warning errors prevent universal controller-protection claims. The contribution is executable, bounded cross-plant evidence checking and conditional transfer assessment.
