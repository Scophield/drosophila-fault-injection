\section{Neural Experiment and Statistical Design}
\subsection{Network, Feedback and Calibration}
The FlyWire v783-derived model\cite{dorkenwald2024neuronal} has 138,639 LIF neurons and 15,091,983 signed, contact-weighted connection rows; cell labels use FlyWire annotations\cite{schlegel2024annotation}. Shiu parameters\cite{shiu2024drosophila} run in Brian~2\cite{stimberg2019brian2}, with 0.1-ms steps, 2.2-ms sensory refractoriness and state/weight restoration per episode. Assumed RFs stimulate 104 LC4 and 210 LPLC2 cells; eight descending cells provide command features (Fig.~\ref{fig:v10f-system}(a--c)).

Between events, $\dot v=(v_0-v+g)/(20\,\mathrm{ms})$ and $\dot g=-g/(5\,\mathrm{ms})$. At $-45$\,mV, reset $(v,g)=(v_0,0)$, $v_0=-52$\,mV; both derivatives pause during refractoriness. Recurrent events add 0.275\,mV per signed contact to $g$ after 1.8\,ms; external events add 68.75\,mV to $v$.

Input starts at 100\,ms with visual period $\delta_{\rm v}=0.020$\,s. In degrees, $\beta$ is world bearing minus heading, $a=(180/\pi)\arctan(0.05/d)$ is half-angle at separation $d$, $\sigma=\max(30^\circ,a)$ and $\ell=(a-a_{\rm prev})/\delta_{\rm v}$:
\begin{equation}
\begin{aligned}
u&=\operatorname{clip}_{[0,1]}[\ell_+e^{-a/60}/150],\\
\lambda_i&=\operatorname{clip}_{[0,150]}[150w_i u e^{-[\operatorname{wrap}(\phi_i-\beta)^2+\psi_i^2]/(2\sigma^2)}]\ \mathrm{Hz}.
\end{aligned}
\end{equation}
Pre-cue $u=0$ masks the initial analytic expansion; the 100-ms input uses 80--100-ms angle history. Wrap maps to $[-180^\circ,180^\circ)$. RF azimuth/elevation $\phi_i,\psi_i$ set $w_i=1$ for LC4 and $1+0.8(\psi_i+30)/90$ for LPLC2; other external rates are zero. A 0.3-m/s pursuer starts 0.25\,m away at $\pm30^\circ$ and targets the agent's segment-start position. Linear segments use starting headings; agent heading updates at segment end, capped at $\pm100^\circ$. Decisions apply next frame. First trigger starts a heading-fixed 0.35-m/s burst 250\,ms later for 450\,ms; otherwise speed is 0.05\,m/s. Actuator events split segments; first contact is solved within them at 0.05-m center separation. Failure latches; resources continue to $H=1$\,s; warnings use pre-contact data.

Per map, 20 passive development episodes (four seeds, five bearings in $[-60^\circ,60^\circ]$) fit affine score $z$. Standardized eight-cell five-frame means over 200--400\,ms predict bearing/$60^\circ$ with ridge penalty 10 and an unpenalized intercept. Trigger threshold is half the development tenth percentile of 200--300-ms episode command means, floored at 2.5\,Hz. Before cue or below threshold, steering is zero; otherwise P/R apply $-600\operatorname{clip}(z,-1,1)$/$-600\operatorname{sgn}(z)$ deg/s outside the burst. Eight held-out validation clusters per RF give RMSE $65.9^\circ/67.8^\circ/67.2^\circ$: $z$ poorly reconstructs closed-loop bearing.

\subsection{Pairing, Cohorts and Endpoints}
Shared uniforms give nested deletions $w_j^{(f)}=w_j\mathbf1[V_{sj}\geq f]$ and input events $\mathbf1[U_{sk\tau i}<\lambda_{ki}\Delta t]$. Indices denote seed $s$, frame $k$, neural step $\tau$, cell $i$ and connection row $j$; $\Delta t=10^{-4}$\,s. Feedback changes $\lambda$, while input variates and row masks remain paired. Seeds and hashes are traceable, without cross-platform bit-identity guarantees.

RF-0/A/B use 24/12/12 independent test clusters, each containing both bearings, two laws and healthy/25\%/50\% deletion: 288/144/144 episodes. New maps independently redraw 314 azimuths from the same hemisphere prior (left $10$--$90^\circ$, right $-90$--$-10^\circ$), preserving identities, elevation and gradients. Each repeats the frozen development recipe, validates on 32 healthy episodes in eight separate clusters, then freezes thresholds. All maps, seeds and failures remain; no test tuning or efficacy stopping occurs. Transfer includes recalibration, not zero-shot or RF-isolated causality.

With $Y=1$ meaning no contact through $H$, registered primary endpoints are paired loss $L=Y_H(1-Y_F)$, gain $G=(1-Y_H)Y_F$ and activity exposure. Net loss $D=L-G$ is derived. The relay-minus-proportional contrast and warnings are prespecified secondary; trigger-timing and clearance/heading diagnostics are post-hoc. For cumulative spikes $S$ and $T_*=\min(T_F,T_H)$, own-stop and common-duration ratios are
\begin{equation}
R_{\rm stop}=\frac{S_F(T_F)}{S_H(T_H)},\qquad
R_{\rm common}=\frac{S_F(T_*)}{S_H(T_*)}.
\end{equation}
Here $T$ is contact-frame end or $H$, at 20-ms resolution. Common duration remains outcome-dependent and does not equate sensory histories; fixed 400-ms/1-s windows are separate endpoints.

Binary loss/gain average both bearings within seed, then seeds. Exposure uses the median of paired ratios, retaining both bearings; warnings pool trial-level confusion counts. Pointwise 95\% CIs resample whole seeds 20,000 times (RNG 20261022 for RF-0; 20261023 for transfer), retaining their complete condition matrix and recomputing the corresponding statistic. CIs condition on stored maps/calibrations. Symmetric-null sign-flip tests use separate Holm families for two baseline and four transfer contrasts. Maps and separate angle/action cohorts are not pooled.

Warnings use only the 400-ms prefix. Command count $C$ sums eight cells across fifteen 20-ms bins in 100--400\,ms; saved rates are exact 50-Hz multiples, allowing lossless integer recovery. Each 32-record healthy validation set gives a linear/type-7 fifth percentile: 14/14.55/13.55 counts in RF-0/A/B. The frozen strict rule $C<Q_{.05}$ does not flag ties; displayed $C/2.4$\,Hz never determines the label. Activity uses a law/bearing-specific healthy reference and a frozen 95th-percentile absolute-log-ratio cutoff; an upper-only comparator flags ratios above two. Forecast uses exact simulated state and pending actuation, holding the current turn; if untriggered at 400\,ms it assumes a 420-ms trigger. Its schedule-only baseline sets future turn to zero. Each RF freezes its fifth-percentile forecast cutoff on healthy validation; these forecasts are not neural-only detectors.
