across protocols v2–v4 and v8; their status statements describe earlier revisions and are not current experimental

by-fault comparison in Sections 12–13. The matched artifact contains raw records, generating-source snapshots
where recorded, current analysis scripts, figure sources and a SHA256/size manifest.

Model, endpoints and statistical definitions
The signed FlyWire-v783 substrate contains 138,639 neurons, 15,091,983 connection rows and approximately 54.5
million contacts. Membrane and synaptic-drive constants are 20 and 5 ms; threshold/reset are -45/-52 mV, delay
1.8 ms, and contact gain 0.275 mV. Both voltage equations pause during the 2.2-ms refractory period. Project
wrappers retain this interval in sensory neurons, unlike the upstream stimulation routine. Fresh integration uses 0.1
ms; historical timestep metadata are unavailable. Independent 150-Hz inputs drive 104 LC4 and 210 LPLC2 cells;
each external event adds 68.75 mV to voltage. Eight DNp01/DNa02/DNp04/DNb01 cells provide the readout. No
background drive is used.
Open-loop endpoints. For eight command cells and T = 0.6 s, r = Ncmd/(8T). Latency is the first spike in this
group, not a completed decision. Total S counts all network spikes. Transmission requires r ≥51.4 Hz, rounding
(94.583333 + 8.229167)/2 = 51.40625 Hz from separate ten-trial sensory/random-drive calibrations. Joint passing
additionally requires r ≤c 94.6875 Hz and S ≤c 39694 with c = 2; sensitivity uses c = 1.5, 3, 4. This is a nested
operational rule, not a validated energy/safety budget.

Matching unequal stopping times and choosing an earlier endpoint are different. The common duration can itself
depend on fault-induced collision. Ratios are reported per scenario before taking medians. Undefined zero-reference
ratios are not silently assigned finite values. Legacy timestamps mark frame starts but cumulative counts include
the completed 20-ms frame; 400 ms uses frame 19.
Frozen controller. Nine passive episodes at -60/-30/0 degrees and seeds 0–2 fix threshold 18.125 Hz, bias b = −20
Hz, scale ℓ= 70 Hz and sign +1.
The fitted window is 250–300 ms.
Steering is ωk = −400 deg/s clip(( ¯dk −
b)/ℓ, −1, 1). dk sums four left rates minus four right rates; ak is the eight-cell mean. Bars average the latest five
frames (all available initially). Triggering requires the current smoothed ¯ak and preceding unsmoothed ak−1 both
to reach 18.125 Hz. The first qualifying frame schedules one burst 250 ms after its end. This is not two consecutive
smoothed crossings. Burst speed/duration are 0.35 m/s and 450 ms, with fixed heading; otherwise speed is 0.05
m/s and heading is limited to ±100 degrees. Cue onset is 100 ms. Geometry uses actual separation, body-frame
bearing and within-frame collision checks at 0.05 m.
Uncertainty. Historical median intervals use 20,000 resamples, seed 0. Reference-aware ratio-of-median intervals
independently resample healthy/fault trials. Dispersion bars instead show 10th–90th trial percentiles. Legacy seed
diagnostics enumerate 33 = 27 ordered draws, yielding only 4–7 distinct medians. New control ranges resample
six complete seed clusters, keeping both bearings together. These conditional percentile ranges are exploratory,
with no confirmatory coverage, significance or equivalence claim. More bootstrap draws do not add independent
observations. Historical open-loop streams were not reset per trial.

Reproduction and exact artifact access
The review package contains main.pdf, this supplement.pdf, a material index and the matching source/data
ZIP. The current revision is prepared locally; it has not been submitted or published. The repository link in the
paper alone does not expose this revision.
For review, the current files must be supplied through a permitted
submission mechanism or an explicitly authorized accessible release. A hash check is evidence of file identity, not
public availability or acceptance.
Read-only reconstruction. From the repository root, install the declared analysis dependencies in a CPython
environment, then use each campaign’s analyze() function to compare against its saved JSON. Entry points are
• tools/analyze_controls_v4.py
• tools/analyze_horizons_v4.py
• tools/analyze_refractory_v4.py
• tools/summarize_prospective.py
The scripts refuse accidental overwrite of their original output directories. Raw reconstructions require no new
neural simulation. Exact build commands, versions and expected external-input hashes are in REPRODUCE.md.
Source and data identity. The artifact manifest lists every included file by SHA256 and size, and binds both
PDFs to their sources. External Connectivity_783.parquet and Completeness_783.csv tables remain separate
dependencies from the released Shiu model repository. Expected hashes and Windows newline normalization are
documented; no table values were changed.
The calibration file remains byte-identical across both prospective
campaigns. No final-release source hash is substituted for a missing older generation hash. The bundled upstream
source snapshots retain their license notice.
Reporting procedure supported by this case study. Report the cohort denominator and condition compo-
sition; identify the functional and activity criteria separately; state the paired stopping rule; inspect full-horizon
activity; and report task outcomes by direction and independent seed cluster.
These reporting choices clarify
evidence without establishing a safety predictor.
Prior work and inherited components.
The manuscript bibliography supplies the full verified citation-
s. The neural substrate follows Shiu et al., Nature 2024, DOI 10.1038/s41586-024-07763-9. Close comparisons
include An’s sparsification study, DOI 10.64898/2026.09.19.752860, and Jo’s endpoint-dependent damage study,
arXiv:2610.19153. NeuroBench, DOI 10.1038/s41467-025-56739-4, already motivates separate functional/system
measures. Our contribution is the quantified case study of cohort, exposure, horizon and feedback-law dependence;
neither adding a nested constraint nor defining a ratio is claimed as an algorithmic invention.
Historical documentation. Protocols v2–v4 and earlier repair reports are retained for chronology. Their old
pending-work statements are superseded by this current supplement and its campaign index. Historical raw records
remain immutable; only current summaries, presentation and delivery files are revised.

Controller-by-fault comparison: frozen calibration
This incremental campaign adds 48 actual full-connectome fault episodes and reuses 24 byte-identical healthy
episodes from the paired controls. The six seed clusters (12–17), both bearings, calibration, receptive-field map,
neural sources and package versions are shared across all six conditions. Healthy outcomes were already known when
this extension was specified; the fault outcomes were not used to retune the controller. Each seed uses Brian2 seed

Paired interaction, activity and threshold sensitivity
The interaction is Dgate −Doriginal, after averaging both bearings within seed. Positive values mean greater net
fault loss under gating. Conditional 95-percent percentile ranges use 20,000 complete six-cluster bootstrap draws
with RNG seed 0. These exploratory ranges are conditional on the frozen calibration and fixed bearings. They
do not establish population coverage, equivalence or a controller mechanism. The +30-degree healthy floor limits
observable loss in that direction.
After observing the conditional bootstrap ranges, we added a post-hoc sign-flip sensitivity, applying all 26 = 64 sign
patterns to the six seed-level interaction contrasts. Under an independent-cluster, symmetric zero-centered interac-
tion null, the two-sided tail fraction is 0.25 at 25-percent deletion (three nonzero clusters) and 0.50 at 50-percent
deletion (two nonzero clusters). This diagnostic is not a randomized controller-assignment test or confirmatory
population inference. The positive percentile range at 25 percent must be interpreted with this sparse support; it
is not a claim of established controller-dependent neural resilience. At 50 percent, both faulty controllers have zero
survivors, so the net-loss contrast reflects healthy baseline success.
