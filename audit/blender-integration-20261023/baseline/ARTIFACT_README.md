VISUAL_REVISION_V9_zh.md. The preceding v9 archive stays immutable; the new
visual archive retains its experiment/analysis bytes and overlays presentation
files with a new manifest and validation binding.

The local revision is distinct from public main/submission and earlier v8.
A final ZIP is verified only when its receipt and independent byte-check report
exist. All three cohorts are complete; STATE.md identifies the matching final
PDF builds and audit paths. Main and supplement are both assessment-v9.

The final package binds main/supplement PDF bytes to TeX, figures, raw episodes,
registrations, calibrated parameters, input maps, exact generating snapshots,
CSV/JSON analyses and independent audit reports. Every member has a SHA256 and
byte size in MANIFEST.json; no Git history, dependency cache, credential folder
or external connectivity/completeness table is bundled. The current Git checkout
retains its history and uncommitted changes separately.

## Three distinct reproduction tiers

1. `verify_artifact_v9.py` uses only Python's standard library to check ZIP CRC,
   every member's bytes, safe paths, validation inputs and both PDF bindings.
   It does not claim new experiment execution or scientific generalization.
2. Saved-data analysis and input/geometry replay use the packaged maps,
   calibrations, registrations and raw JSON without a connectome or new neural
   simulation. Install the supported libraries; follow REPRODUCE.md into NEW
   output directories. Use analyze_task_v9_exportfix.py, with its documented
   export-only correction. Full neural-state correctness is outside replay scope.
3. Fresh neural execution needs a Git checkout, separate Drosophila_brain_model
   tables and the pinned environment. Different source/runtime/input requires a
   separately labeled replication registration, not appending to old outputs.
   Recreate development/validation before a newly designed test. Do not promise
   cross-platform bit identity or change seeds until results look favorable.

The original dirty-workspace backup is not the scientific ZIP. The editing-
history preservation report records a completed local audit; repeating that
specific check needs the original backup/workspace. The standalone ZIP verifier
checks the scientific bundle without requiring unrelated old build files.
