\section{Executable Evidence and Audit Cost}
One JSON file per paired condition records frames and actuator segments. Source, map, calibration and input bindings reject incomplete or mixed matrices. Independent replay reconstructs geometry, decisions and inputs without the task implementation or connectome; arithmetic checks verify effects and warning denominators. Mutation tests reject inconsistent headings, bursts and horizon flags and future-data leakage in prefix metrics. A tiny Brian~2 test checks state and fault-weight restoration.

The core neural campaign takes 14,393\,s with three CPU workers; median episode wall time is 145.5\,s. Independent trace/input replay takes 34.4\,s. These perform different work: replay consumes recorded neural outputs and does not certify neural-state correctness or establish a simulation speedup. No hardware energy or area is inferred.

The package supplies raw JSON/CSV, generating snapshots, local registrations, TeX, figures and checksums; external tables remain separate. Registrations lack external timestamps. A logged CSV fix separates numeric-margin and Boolean-warning columns; frozen sources and raw records remain intact. Reanalysis/replay needs no neural execution. Public main may predate this revision.
