# 视觉任务示例:移动逼近威胁的逃逸转向(全脑连接组在环)

本目录在论文实验之外,提供一个独立的演示:完整果蝇全脑连接组网络对移动逼近视觉威胁产生逃逸转向决策,并比较故障注入前后的行为变化。**不修改、不依赖原论文实验的任何结论。**

## 任务选择依据

LC4/LPLC2→GF/DN 是果蝇对逼近物体(loom)的**逃逸**通路(Klapoetke et al. 2017:LPLC2 感受野 ≤60°、径向扩张选择;Ache et al. 2019:LC4 编码逼近角度变化;Dombrovski et al. 2025 Nature:LPLC2→GF 突触背腹梯度)。经典的移动目标追踪需要 LC11/LC21 类小目标检测通路,与本仓库已验证的 LC4/LPLC2 读出不匹配,故不做追踪演示。8 个下行命令神经元(DNp01/DNa02/DNp04/DNb01,左右各一)天然构成左右差读出结构,用于逃逸转向决策。

## 模块划分

| 模块 | 文件 | 性质 |
|---|---|---|
| 2D 场景与威胁脚本 | `run_closedloop.py`(目标逐帧追踪逼近) | 外部环境 |
| 感觉编码(loom→逐细胞率) | `encoder.py` | **假设性映射**(见下) |
| 全脑网络 | `vision_core.py`(完整 138,639 神经元 / 15,091,983 连接 Brian2 LIF,**不裁剪**) | 已验证(与论文同源) |
| 输出读出 | 8 个下行命令神经元(4 型 × 左右)+ 左右差 | 已验证 |
| 读出→转向映射 | `calibrate_readout.py` → `calib.json`(**仅用训练条件校准后冻结**) | 校准(训练/测试分离) |
| 执行器 | 2D 质点运动学:行走转向 + GF 式弹射(定向 250 ms 后 0.35 m/s 弹射 0.45 s,弹射中不转向) | 外部控制器 |

分工声明:**全脑网络决定**转向意图(8 DN 左右差)与响应幅度(弹射触发判据 = 网络活动);**外部控制器只决定**质点运动学积分与威胁脚本。场景变量(威胁方位)从不进入控制器(对照 `handrule` 模式读场景方位角,仅供上界参考,不属于本架构)。

## 结果概要(全部为真实仿真记录,复现命令见下)

**A 开环**(15 条件 × 6 种子,`analyze_openloop.py`):
- 无刺激 / 静态刺激:全网 0 尖峰(全部种子);
- 方位编码:左右差随方位单调(−60°→+81.7 Hz、−30°→+78、0°→+28、+30°→−68、+60°→−82,6 种子符号一致率 100%);
- 剂量单调:逼近速度 0.5→1.0 m/s 使左右差约 11.7→13.3 Hz、目标半径 0.5→2.0 m 约 21.7→26.7 Hz;
- 背腹梯度:腹侧(−30°)121.7 Hz < 水平 233 < 背侧(+40°)250 Hz(DN 命令率中位,与 Dombrovski 梯度一致)。

**B 校准**:仅用训练条件(方位 −60°/−30°、慢速逼近);`bias`、`lr_ref`、`data_sign` 冻结于 `calib.json`,测试方位(+30°/+60°)不参与任何参数。

**C 闭环无故障**:24/24(4 方位 × 6 种子)逃逸成功,最小距离中位 0.078–0.112 m(碰撞判据 = 威胁半径 0.05 m)。

**D 因果对照**(同刺激、同时限、同种子):
- `silence`(8 DN 输出断开):0/12 逃逸——直线爬行被追踪威胁追上;
- `flip`(左右差取反):0/12——逃向威胁;
- `handrule`(外部规则,按方位角线性转向):12/12——上界参考(读场景变量,不属于本架构)。
即任务性能**由全脑网络输出因果决定**。

**E 故障注入**(brain 模式,12 集/故障):
- F2_25(随机损坏 25% 连接):逃逸率 92%,最小距离基本保持;
- F2_50(50% 连接):75%,退化呈剂量依赖;
- F4_1pct(输出强度前 1% 单元静默,排除兴奋池与读出):**100%,几乎无损**;总尖峰中位 9.9k–13.8k,低于无故障(13k–18k),**无过活动**。
行为层面的 F4 保持与论文开环结论(输出传输保持 76.5%)方向一致:hub 输出静默后,分布式通路仍能驱动读出。注意这不是"hub 无关紧要"的证据——论文的机制分析(匹配断连对照、E/I 控制)仍是必要的。

**演示视频**:`results_vision/demo_escape.mp4`(三面板:无故障 / F2_50 / F4_1pct,同一威胁轨迹与种子;上排轨迹与威胁逼近,下排 8 DN 逐帧命令率与弹射标记)。

## 演示关键机制(如实记录)

- **正前盲区**:方位 0° 时左右差读出对称失效(开环 lr≈28 Hz 残余不对称驱动);闭环测试集合因此取 {±30°, ±60°},这是 8 DN 左右差结构的真实局限,如实呈现。
- **弹射定向**:GF 式弹射在触发后延迟 250 ms(定向反射时标)沿当时朝向弹射;弹射中不转向,落地后继续行走转向。该执行器参数对所有模式(含对照)一致,不构成对 brain 模式的偏袒。
- **u 门控**:loom 驱动仅在威胁出现(t≥100 ms)后非零,保证无刺激/静息段零驱动。

## 已验证 vs 假设(诚实清单)

**已验证(本仓库/论文既有结果)**:全脑 LIF 网络构建、零基线、逃逸全池驱动的 94.7 Hz 读出、θ=51.4 Hz 判据、故障注入管线(F1/F2/F4/F5 语义)。

**本演示新增验证(A 阶段,已跑通)**:视觉 loom 刺激下 DN 群体的方位/剂量响应可重复性、左右差符号跨种子一致性(100%)、无刺激零响应、背腹梯度方向。

**显式假设(影响结论强度,如实标注)**:
1. RF 中心近似:左半脑细胞分配到左视野(方位 +10°~+90°)、右半脑到右视野(−10°~−90°),区间内均匀随机(固定种子 `RF_SEED=20260201`,完整映射存于 `rf_map.csv`);逐细胞真实感受野无公开数据,仰角中心随 soma 高度线性映射(−30°~+60°)。
2. 背腹梯度:LPLC2 输出增益按 soma 高度线性加权(依据 Dombrovski et al. 2025 的定性梯度),增益常数 `GRAD_GAIN=0.8` 为假设参数。
3. looming 强度包络 u(t)=clip(dα/dt/150°/s)·exp(−α/60°),为 Gabbiani 型 ψ 函数的简化;LC4/LPLC2 的动态增益未做实验标定。
4. 转向语义:左右差→转向方向的符号由训练条件校准(非文献先验);DNa02 左右对的转向功能有 Yang et al. 2024 (Cell) 依据,其余 3 型的转向贡献未验证。
5. 逃逸行为映射:生物果蝇为 GF 介导的跳跃起飞;2D 演示以"定向后弹射 + 行走转向"的质点近似,弹射延迟(250 ms)与速度(0.35 m/s)为演示参数,不代表起飞运动的定量标定。

## 运行命令(最小复现序列)

```bash
git clone https://github.com/philshiu/Drosophila_brain_model.git   # 上游数据(SHA256 见主 README)
ln -s <parent>/Drosophila_brain_model .
pip install -r requirements.txt
cd sim_vision
python3 run_openloop.py            # A:开环 15 条件 × 6 种子(~25 min 单核)
python3 analyze_openloop.py        # 汇总表 + 方向编码检查
python3 calibrate_readout.py       # B:训练条件校准(冻结 calib.json)
python3 run_closedloop.py --tag main --modes brain --seeds 0,1,2,3,4,5 --phis=-60,-30,30,60   # C(~20 min)
python3 run_closedloop.py --tag main --modes silence,flip,handrule --seeds 0,1,2 --phis=-60,-30,30,60   # D
python3 run_closedloop.py --tag main --modes brain --faults F2_25,F2_50,F4_1pct --seeds 0,1,2 --phis=-60,-30,30,60   # E
python3 analyze_closedloop.py      # C+D+E 汇总表(聚合 closedloop_main_*.jsonl)
python3 make_video.py --tag main --phi -30 --seed 0   # 视频(需对应 episode 记录已生成)
```

注意:argparse 负数参数必须用 `--phis=-60,...` 等号形式;各段输出为独立 `closedloop_main_<modes>_<faults>.jsonl`,`analyze_closedloop.py` 自动聚合;单进程运行(构建全脑网络峰值内存约 1.1 GB,勿并行)。

## 阶段判据(A–E)

- **A**:无刺激全网 0 尖峰;方位条件左右差符号跨种子一致;loom 速率/尺寸呈剂量趋势;背腹梯度方向正确。
- **B**:校准仅用 φ∈{−60,−30}、v_0p5 训练条件;`calib.json` 冻结后用于全部测试轨迹。
- **C**:闭环逃逸成功率与最小距离(真实记录,失败照实展示)。
- **D**:silence(DN 输出断开)与 flip(左右反转)性能应显著劣于 brain;handrule 为外部规则上界参考(其读场景方位角,不属于本架构)。
- **E**:F2/F4 故障应用于全脑网络(统一刺激/时限/种子);同步检查总尖峰(过活动检查);F4 为输出静默(权重置零),不是神经元删除。
